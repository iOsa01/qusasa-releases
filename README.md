# قُصاصة — الإصدارات

إصدارات تطبيق **قُصاصة** لأندرويد: تحميل المقاطع من المنصات، وتقسيمها وقصّها وتحريرها، وإرسالها إلى سناب.

- **التنزيل:** [أحدث إصدار](https://github.com/iOsa01/qusasa-releases/releases/latest) — ملف `qusasa-latest.apk`.
- **التحديث:** بعد التثبيت الأول، يحدّث التطبيق نفسه من **الإعدادات ← تحديث قُصاصة**؛ يتحقق من بصمة الملف (SHA-256) ومن شهادة التوقيع قبل التثبيت.
- `latest.json` هو بيان الإصدار الذي يقرؤه التطبيق.

هذا المستودع للإصدارات فقط: لا شيفرة ولا أسرار.
